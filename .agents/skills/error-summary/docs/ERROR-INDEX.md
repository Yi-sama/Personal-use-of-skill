## 检索规则

1. 先读取本文件，不先读取全部详细案例。
2. 选择匹配的 HASH。
3. 执行精确搜索，例如：rg -n -C 20 "75e0ba56ceb6" docs work。
4. 只读取命中案例及其必要上下文。
5. HASH 是永久检索键，案例内容更新后也不得改变。
